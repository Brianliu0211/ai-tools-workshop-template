# 💡 想法收件匣

> 想法的生命週期：`靈感 → 構想（💭）→ 評估 → 開工 → 可用／放棄`。
> 決定要做時，再依 [新工具建立流程](00_公共規格/新工具建立流程.md) 建立工具資料夾，並在這裡把狀態改成「→ 已轉成 NN_工具」。
