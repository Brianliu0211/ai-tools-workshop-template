# 🔑 金鑰登記簿

記錄工坊每一把金鑰的「資料」：名字、給誰用、存在哪、何時到期、怎麼重發。

> ⛔ **本檔絕對不寫金鑰的值**（連前幾碼都不寫）。值只放在保險箱：工具的 `.env`（已被 .gitignore 排除）、自動化平台的 Credentials、密碼管理器。
> 本檔可以進 git、AI 可以讀取與維護；被看到也拿不到任何鑰匙。

## 📋 登記表
