# 🛠️ 我的小工具工坊

個人客製化小工具的開發與存放倉庫。第一次使用請先看 [使用說明](使用說明.md)。

---

## 📁 工具清單

| # | 工具 | 技術 | 說明 | 狀態 | 發佈 | 啟動方式 |
| :-: | :--- | :--- | :--- | :-: | :-: | :--- |
| 01 | （範例，建立第一個工具後刪除這列） | C# 托盤 | 一句話說明這個工具解決什麼問題 | 💭 構想中 | — | — |

> **狀態**：💭 構想中｜🟡 開發中｜🟢 可用｜🟠 暫停｜⚪ 停用
> **發佈**：🌐 GitHub｜📤 雲端硬碟（執行檔 + README）｜💻 僅本機
> 標籤定義與版本控制方式見 [新工具建立流程](docs/00_公共規格/新工具建立流程.md)。每個工具資料夾都是獨立的 git repo，本工坊 repo 只存規則與文件。

## 📂 目錄結構

```
工坊/
├── .agents/              AI 規則（AGENTS.md）
├── .obsidian/            Obsidian 設定（以本資料夾為 Vault）
├── CLAUDE.md             讓 Claude Code 讀到 AGENTS.md 的入口
├── docs/
│   ├── 00_公共規格/       工坊共用規範
│   ├── 03_開發日誌/       工坊規範調整日誌（依月份）
│   ├── 04_學習筆記/       學新工具、裝環境、搞懂概念的紀錄（依月份）
│   ├── 作品紀錄/          工坊以外的作品（一個作品一個資料夾）
│   ├── 知識庫/            開發網概念筆記（工具 / 元件 / 技術 / 問題類型）
│   ├── 想法收件匣.md      還沒做的點子
│   ├── 金鑰登記簿.md
│   └── 工具包.md
├── NN_工具名/            每個工具一個編號資料夾（各自獨立 git repo）
└── _archive/             停用的工具（需要時才建立）
```
